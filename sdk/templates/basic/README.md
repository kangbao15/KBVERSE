# My KBVERSE Mod

A starter project for KB Loader API v1.

## Development

Use the official SDK CLI from the KBVERSE repository:

```powershell
node sdk/bin/kb.js validate path/to/your-mod
node sdk/bin/kb.js build path/to/your-mod
```

The resulting `dist/<mod-id>.kbmod.json` can be imported with KB Mod Manager.

See the SDK documentation for permissions and API reference.
